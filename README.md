# Bubble Voice — ไกด์เสียงอ่านชื่อ

หน้าเว็บ: https://bennyeiei.github.io/bento-soundpad/ · ลิงก์หมวดของงาน: `?cat=kkt21`

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `library.json` | **คลังกลาง** — คำละหนึ่งรายการ `{word, file, aliases, match}` + `ignore` |
| `audio/library/<คำ>.mp3` | เสียงอ่าน หนึ่งคำหนึ่งไฟล์ ใช้ได้ทุกงาน |
| `sounds.json` | สิ่งที่หน้าเว็บแสดง: หมวดละงาน (`auto: true` = สร้างจากบทอัตโนมัติ) + 📚 คลังเสียง |

- `match: "any"` = จับทั้งชื่อผู้พูดและในบทพูด · `"speaker"` = จับเฉพาะชื่อผู้พูด
  (ใช้กับคำสั้นที่เป็นคำไทยด้วย เช่น หลาน ↔ หลานสาว)
- คำที่ยังไม่มีไฟล์ (`file: null`) ขึ้นเป็นปุ่มสีเขียว กดแล้วเครื่องอ่านให้ (TTS ภาษาไทย)
